Estructura Modular del Proyecto

1. Limpieza de Datos

Carga los CSVs originales, verifica nulos, elimina duplicados y formatea la data limpia.

📁 1_limpieza_datos/
2. Entrenamiento

Entrena los 3 modelos con Scikit-Learn y exporta los archivos binarios serializados.

📁 2_entrenamiento_modelos/
3. Análisis y Métricas

Calcula MSE, RMSE y R², estandariza coeficientes y genera las gráficas de resultados.

📁 3_analisis_evaluacion/
4. Interfaz Web

Servidor web en Flask/Streamlit para ingresar datos y calcular predicciones en pantalla.

📁 4_interfaz_web/

Galería de Gráficos de Resultados

1. Relaciones - Precio del Dólar

Comportamiento del precio del dólar con respecto a Día, Inflación y Tasa de interés.

2. Relaciones - Niveles de Glucosa

Relación funcional entre Edad, IMC y Actividad Física con el nivel de Glucosa.

3. Relaciones - Consumo de Energía

Relación del consumo eléctrico frente a Temperatura, Hora del día y Día de la semana.

4. Matrices de Correlación de Pearson

Matriz de calor de correlaciones cuantitativas entre variables independientes y dependientes.

Instrucciones de Ejecución del Proyecto

1. Ejecutar el Pipeline Completo:
python main.py
2. Iniciar la Aplicación Web Interactivas:
python 4_interfaz_web/app.py
